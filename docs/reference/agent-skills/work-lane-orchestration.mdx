# Collaboration Entry

For repository development, read the repository's `AGENTS.md` and the
task-relevant [Guardrail Catalog](../guardrails/_agent_catalog.yml).
Under SCQ_Design, `$scq-collaboration-roles` resolves the repository owner
and `develop-main` delivery profile.

This retained documentation URL replaces the former portable orchestration
template with a host pointer. It defines no additional roles, Git mechanics,
acceptance rules, or required Skill installation. Other hosts use their own
declared collaboration authority.

Package users can read [Notebook Roles](../research-contracts/notebook-roles.md)
and the package API documentation without the SCQ development configuration.
